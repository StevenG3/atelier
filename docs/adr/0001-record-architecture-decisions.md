# ADR-0001: 用 ADR 记录架构决策

- 状态: 已接受
- 日期: 2026-05-29

## 背景
双 Agent 协作中，上下文很容易丢失。Claude 不是常驻进程，每次被唤起都需要重新理解项目；Codex 也需要稳定的决策依据。口头/聊天里的决定无法沉淀。

## 决策
所有有后果的架构决策，都以一份 ADR 记录在 `docs/adr/` 下，编号递增。Claude 在做重大决策时负责起草。

## 备选方案
- 只写在 Issue 评论里：会被淹没，难检索。
- 写在 wiki：脱离代码，容易过期。

## 后果
Agent 和人类都能快速回溯"为什么当初这么定"，减少重复讨论，节省 Claude 额度。代价是要保持纪律去写。
